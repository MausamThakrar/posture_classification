# Dataset Description

This folder contains example data for the posture classification project.

## File: `sample_posture_data.csv`

This synthetic dataset simulates pressure sensor values collected from a smart chair.

### Columns

| Column              | Description                 |
|---------------------|-----------------------------|
| sensor_front_left   | Pressure sensor front-left  |
| sensor_front_right  | Pressure sensor front-right |
| sensor_back_left    | Pressure sensor back-left   |
| sensor_back_right   | Pressure sensor back-right  |
| sensor_middle       | Center support pressure     |
| label               | Target posture class        |

### Posture Classes

- upright  
- slouch  
- lean_left  
- lean_right  

This file is for demonstration only.
